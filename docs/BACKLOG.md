## Product contract

Reconstruct files for **static, offline inspection only**. Preserve supported parsed file paths and contents; exclude predefined configuration files entirely rather than changing their contents (policy: [`docs/EXCLUSIONS.md`](EXCLUSIONS.md)). Protect the local filesystem with path validation, resource limits, isolated output, and fresh-only writes. Never execute recovered code. Inputs and outputs can contain confidential data and require separate review before distribution.
