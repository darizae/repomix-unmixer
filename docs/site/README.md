# Static documentation landing page

Open [`index.html`](index.html) locally in a browser to preview the responsive, dependency-free documentation landing page. No JavaScript, tracking, font downloads, or network requests are required.

The page is **not deployed**. Links to Markdown documents are for a local checkout; a hosted release would need a proper site build or rewritten URLs. The social-card SVG is at [`../../assets/social/preview.svg`](../../assets/social/preview.svg); export a 1200×630 PNG from that SVG when configuring GitHub's social preview or a production Open Graph image.

Before deployment, verify live URL paths, GitHub Pages configuration, manual desktop/mobile rendering, accessibility contrast, license rights and approval to publish. Those checks remain deferred in the release backlog.
