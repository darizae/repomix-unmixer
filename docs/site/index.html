Files you can inspect. Not code you must run.

A focused inverse workflow for existing Repomix text exports.

01 / FORMATS

Markdown, XML, JSON

Restore supported exports into a readable directory tree. Known fidelity limits are documented.

02 / DEFENSE

Validate before writing

Reject traversal and ambiguous paths, collisions, oversize content and existing destinations.

03 / WORKFLOW

CLI, batches, agent skill

Dry-run an export, reconstruct several exports, or guide an agent through static-only inspection.

Two commands to reconstruct.

Install the CLI from this trusted checkout. Run the dry run first, then use a fresh destination.

The tool does not execute recovered code. Do not build, install, test, or run anything inside the reconstructed folder.

$ python3 -m pip install .
$ unmix-repomix export.md output/ --dry-run
$ unmix-repomix export.md output/
